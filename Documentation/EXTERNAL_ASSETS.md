# External assets

Only resources actually included in the project. Everything else (clothes, hair, faces, demon parts, textures, VFX,
music, SFX, the inhale sound) is generated by code. Originals are kept intact under
`Assets/_BreathOfEclipse/ThirdParty/<Creator>/`; everything derived is built at runtime inside the game's own code.

Never import ripped models or official characters from other franchises.

### Your own player model (VRoid Studio / Humanoid FBX)

Put `Player.vrm` (with UniVRM installed) or a Humanoid FBX / prefab in `Assets/_BreathOfEclipse/Characters/Import/Player/`
and run *Breath of Eclipse → Characters → Import Player Model*: Humanoid rig, skeleton validation, toon materials,
sockets and the hybrid animation (Quaternius clips + combat IK) are set up and the model becomes the player's
VisualModel. *Use Built-in Anime Swordsman* reverts.
