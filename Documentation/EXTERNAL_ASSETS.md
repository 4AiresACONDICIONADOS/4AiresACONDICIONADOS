# External assets

Only resources actually included in the project. Everything else (models, textures, VFX, music, SFX, the inhale
sound) is generated by code.

| Asset | Source | URL | License | Author |
|---|---|---|---|---|
| Technique voice clips v0.3 (`Core/Resources/BreathOfEclipse/Voice/es-419/<style>/*.wav`), one delivery per breathing style | Generated locally with `Tools/Generators/generate_voice_lines.py` (report: `Tools/Generators/voice_report.txt`) | — | Output of the model below (no cloning, no real actor imitated) | — |
| Chatterbox Multilingual TTS 0.1.7 + weights (tool only, not shipped), built-in generic voice | PyPI `chatterbox-tts`, Hugging Face `ResembleAI/chatterbox` | https://github.com/resemble-ai/chatterbox | MIT (code and weights). Outputs carry Resemble's inaudible "Perth" watermark | Resemble AI |

Replace any clip with a recording of the same file name (see `VoiceLibrary` in `Scripts/Runtime/Audio/VoiceChannel.cs`).
A cloud voice (ElevenLabs, paid plan with commercial rights, generic library voice) is prepared in the generator:
set `ELEVENLABS_API_KEY` and `ELEVENLABS_VOICE_ID` in the environment and run `--provider elevenlabs` (untested).

## Recommended, not included (need the user's account or a manual download)

No external model, texture or animation is included (v0.3.0). Import them with *Breath of Eclipse → Characters* (see below). Checked licenses (all allow use in a commercial game):

| # | Asset | Use in this project | License |
|---|---|---|---|
| 1 | VRoid Studio (pixiv) + UniVRM | Original anime protagonist → `CharacterVisualProfile.modelPrefab` | VRoid: models you create are yours; UniVRM: MIT |
| 2 | Quaternius Universal Animation Library (https://quaternius.com/packs/universalanimationlibrary.html) | Humanoid locomotion / combat clips for Mecanim | CC0 |
| 3 | Quaternius Stylized Nature MegaKit (https://quaternius.com/packs/stylizednaturemegakit.html) | Trees, rocks, plants for Moonlit Forest | CC0 |
| 4 | Mixamo (Adobe account) | Sword attack / draw / sheathe animations | Royalty-free in projects; no raw redistribution |
| 5 | Quaternius monster packs (https://quaternius.com/) | Base meshes for Nightspawn / Hollow Oni | CC0 |

Never import ripped models or official characters from other franchises.

### Exact files for the player model (v0.3.0 import pipeline)

| Asset | Source / URL | License | Exact file needed | Where to put it |
|---|---|---|---|---|
| Original anime swordsman | VRoid Studio — https://vroid.com/en/studio (free app, pixiv account only to publish) | Models you create are yours (commercial use allowed) | Your character exported as `.vrm` (VRM 0.x) | Import with UniVRM, then select the prefab |
| UniVRM importer | https://github.com/vrm-c/UniVRM/releases | MIT | `UniVRM-0.x.x_xxxx.unitypackage` (or the UPM git URLs in its README) | Import into the project |
| Humanoid animations (idle, walk, run, sprint, jump, roll, block, sword slashes, hit, knockdown, get up) | Quaternius Universal Animation Library — https://quaternius.com/packs/universalanimationlibrary.html | CC0 | The free "Standard" download, `.fbx` files | `Assets/_BreathOfEclipse/Characters/Import/` |
| Extra katana attacks / draw / sheathe | Mixamo — https://www.mixamo.com (Adobe account) | Royalty-free in projects, no raw redistribution | FBX for Unity, "Without Skin", 30 fps (e.g. Great Sword Slash, Sword And Shield Block) | `Assets/_BreathOfEclipse/Characters/Import/` |

Then: *Breath of Eclipse → Characters → Build Player Visual From Selection* on the model. It imports FBX files in that
folder as Humanoid, builds the Animator Controller (states matched by clip name), a CharacterVisualProfile and
assigns it to the GameDatabase. *Use Procedural Mannequin* reverts.
